01 / TRIAGE

Soal dikasih file berbeda? Mulai di sini.

Pilih file dari komputermu atau tulis petunjuk soal. Analisis format dilakukan lokal di browser (tidak di-upload). Rekomendasi hanyalah titik awal, bukan deteksi kerentanan otomatis.

Isi petunjuk atau pilih file, lalu pilih Analisis & pilih jalur.

⏱ 60 detik pertama setiap soal

01
Baca soal dan bentuk flag

Catat kategori, file/link/host-port, batas, format flag, dan clue eksplisit.

02
Jangan percaya ekstensi

file FILE → xxd -l 64 FILE → strings -a FILE untuk artefak lokal.

03
Cari sinyal termurah dulu

Metadata, source, cookie, header, riwayat Git, atau string. Hindari scanner berat sebelum perlu.

04
Uji satu hipotesis, baca output

Output yang berbeda belum otomatis flag. Cocokkan dugaan dengan hasil yang bisa direproduksi.

05
Ganti jalur atau skip

Jika 12–15 menit tidak ada kemajuan, catat dan pindah ke soal lebih cepat.

Jenis challenge berbeda → langkah berbeda. Setelah satu alat menghasilkan file baru, jalankan file lagi dan pilih playbook lain. Jangan memaksa tool awal sepanjang proses.

05 / TOOLSET

Tools dan cara instalasinya di Kali Linux

Tiap tool memuat kegunaan, perintah instalasi, contoh pemakaian, dan situs resmi/GitHub. Tidak perlu instal semuanya; utamakan yang relevan dengan file soalmu.

⚡ INSTALASI TERPILIH
sudo apt update && sudo apt install -y file xxd ripgrep git curl jq unzip 7zip netcat-openbsd python3-venv binutils libimage-exiftool-perl binwalk stegseek steghide ffuf sqlmap gdb tshark sleuthkit pngcheck zbar-tools poppler-utils ffmpeg
APT dapat berbeda menurut versi Kali. Gunakan apt-cache show NAMA_PAKET sebelum instal. GUI/versi besar (Ghidra, JADX, Wireshark) dipasang jika dibutuhkan. Python library gunakan venv; jangan sudo pip install. Format HOST:PORT hanya untuk instance lomba.

⚖️ Etika & batas kompetisi

Gunakan endpoint, akun, dan host yang secara eksplisit termasuk ruang lingkup challenge. Periksa aturan panitia terkait penggunaan AI, internet, tool otomatis, dan kolaborasi. Binary tidak dikenal sebaiknya dianalisis dalam VM/sandbox; jangan jalankan file di laptop utama.

Kartu bukan “solusi pasti” untuk setiap challenge. Jika hasil tidak sesuai, kembali ke tahap inspeksi artefak dan hipotesis.
